# Безопасное сообщение об ошибках

Не помещать в публичные issues подключения, токены, защищённые env, исходники рабочей конфигурации, captures, персональные данные или дампы процессов. Для воспроизведения использовать синтетический текст и собственную безопасную fixture.

Публикация исходников не включает разрешение открывать сетевой MCP-доступ к рабочему Конфигуратору. Профиль конкретной установки, credentials, разрешения записи и локальное состояние хранятся вне общего кода.

Приватный канал владельца для уязвимостей ещё не назначен; не публиковать эксплуатационные детали до определения такого канала.
